# Skill — schedule and workday

Scope: current calendar, tasks, timing and execution feasibility.

- Read `PERSON.md` plus the relevant domain/project owner only for durable/fallback timing constraints.
- Google Calendar owns current events/availability; TickTick owns current tasks/reminders when claim-relevant.
- Scheduled/planned time is not proof an activity happened.
- Use exact day-level live timing for decisions where commute, work, training, preparation or deadlines affect feasibility.
- Add the domain whose activity is being scheduled instead of treating time as the whole problem.

This skill owns procedure only, never mutable calendar/task state.
