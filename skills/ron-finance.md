# Skill — finance

Scope: budgeting, spending, debt, savings, investment and financial trade-offs.

- Read `domains/finance.md` for dated fallback and durable decisions.
- Current balances, payments, income changes and transactions require direct/live evidence; current rates/prices require fresh sources.
- Do not promote dated fallback amounts to live truth for consequential decisions.
- For a requested current derived value, preserve provenance/status for every mutable input: if an input is stale, historical or modelled, label that input the same way and never describe it as current or as the current structure merely because the derived result is left `UNKNOWN/UNVERIFIED`.
- Optimize total expected value including money, time, reversibility, downside and execution friction; add schedule or the purchased/income domain when causal.
- Keep account/card/credential data out of Ron OS.

This skill owns procedure only, never mutable financial state.
